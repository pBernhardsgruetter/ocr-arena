Method

  • Corpus: seeded synthetic German/English business pages (letters, tables, photos, handwritten form fields), rasterised to image-only PDFs with no text layer; profiles differ in scan quality. Ground truth is exact.
  • CER / WER: Levenshtein distance over characters / whitespace tokens after Unicode and Markdown normalisation (table pipes, headings and escapes are not penalised).
  • Hallucination: output tokens aligned to the truth. An inserted token, or a replacement that is not similar to the truth token (fuzzy ratio < 60), counts as fabricated. Similar-but-wrong tokens are misreads (ordinary OCR errors). Missing tokens are omissions. Rate = fabricated / output tokens.
  • Wrong numbers: numeric tokens in the output that do not exist on the page. Near-misses differ from a real number by ≤ 2 characters (e.g. swapped digits): plausible-looking and the most dangerous.
  • Handwriting found: best fuzzy window match of each handwritten field anywhere in the output (output has no regions), 100% = verbatim.
  • Table F1: cell-level F1 after matching rows; a ParseBench-style subset, not the official scorer. Reading order: share of paragraph pairs in correct order.
  • Speed: wall-clock per document in an isolated process, one engine at a time, single run. Peak memory is the process maximum RSS.
  • Limits: noise-garbled tokens can count as "fabricated" on very bad scans, so compare engines on the same profile. Synthetic handwriting is easier than real handwriting.
